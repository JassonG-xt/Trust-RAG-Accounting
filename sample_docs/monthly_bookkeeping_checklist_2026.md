# Monthly Bookkeeping Document Checklist (2026)

Monthly bookkeeping for a client engagement requires the following
artefacts before month-end close. Missing items must be requested from
the client and tracked in the engagement log.

## Required artefacts

- [ ] **Bank statements** — every operating account, full month.
- [ ] **Sales invoices** — both issued and any voided originals.
- [ ] **Purchase invoices** — including delivery / platform service
      invoices (see client-specific compliance rules where applicable).
- [ ] **Payroll records** — salary, social insurance, and housing fund
      slips.
- [ ] **Reimbursement forms** — with the manager approval note attached
      when required by the current reimbursement policy.
- [ ] **Approval documents** — wherever a transaction's policy
      requires explicit authorization.

## Missing material

If any of the above is missing at month-end, the entry must be paused
and the missing item requested from the client. Do **not** book entries
against a "best guess" — there is no legitimate accounting use case for
booking a transaction with a missing supporting document.
